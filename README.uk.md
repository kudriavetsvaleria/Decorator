# Decorator — Курсовий проект з патернів проєктування

Невеликий C++ проєкт, що демонструє **патерн Decorator** у дії.  
Ця курсова робота показує, як поведінку об’єктів можна динамічно розширювати без зміни їх класів.

## 🚀 Що робить проект

- Демонструє реалізацію **патерну Decorator**  
- Використовує C++ та базові **принципи ООП**  
- Дає уявлення про динамічне додавання поведінки

---

## 🛠️ Як це працює

Патерн Decorator дозволяє **обгортати об’єкти**, щоб додавати нову поведінку **без зміни структури класу**.  
У цьому проєкті ви знайдете:

- Базові компоненти  
- Конкретні декоратори  
- Приклади використання для розширення поведінки
