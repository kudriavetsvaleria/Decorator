# Decorator — Курсовий проект з патернів проєктування

Консольний застосунок на **C++**, розроблений для демонстрації патерну проєктування **Decorator**. Проєкт показує, як можна динамічно розширювати поведінку об’єктів без зміни їх класів.

## ✨ Можливості

- **Патерн "Decorator"**: Додання нової поведінки до об’єктів за допомогою обгортання:
  - Базові компоненти
  - Конкретні декоратори
  - Динамічне розширення поведінки
- **Гнучка структура**: Легке додавання нових функцій до існуючих класів без зміни їхнього коду.
- **Розширення**: Легке створення нових декораторів для різних типів поведінки.
  
---

## 🏗️ Патерн Проєктування

У цьому проєкті реалізовано патерн **Decorator**, що дозволяє динамічно додавати нові функціональні можливості до об’єктів без зміни їх базового коду.

1.  **Базові компоненти** — основні класи без додаткових можливостей.
2.  **Конкретні декоратори** — класи, що додають додаткові функціональні можливості.
3.  **Приклади використання** — застосування декораторів для розширення поведінки.

---

## 🚀 Як запустити

1.  Відкрийте рішення `CourseWork_Decorator.sln` у **Visual Studio**.
2.  Оберіть конфігурацію **Release** або **Debug**.
3.  Зберіть рішення (Build -> Rebuild Solution).
4.  Запустіть застосунок (F5).
